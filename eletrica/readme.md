# Aviso

Este repositório **contém apenas minhas notas pessoais**.  

- Não é material oficial e **não é associado a nenhum professor ou instituição**.  
- Serve apenas para **consultar com base no SIGAA ou para estudo próprio**.  
- **Não deve ser usado para trapacear** ou substituir aulas e conteúdos oficiais.  

Para acessar qualquer conteúdo oficial, sempre consulte o SIGAA ou os professores da sua instituição.  

---

## Sobre este repositório

- Contém apenas arquivos de referência, exemplos e minhas anotações.  
- Todo o material didático completo está disponível **apenas na página oficial do curso ou com os professores**.  
- Alterações aqui **não afetam nenhum conteúdo oficial**.  

---

## Objetivo

Este README serve para:

1. Informar que o conteúdo é **pessoal e não oficial**.  
2. Orientar os usuários a **não usarem para trapacear**.  
3. Servir como referência para a **organização das minhas notas**.  

---

## Estrutura do repositório

- Cada pasta corresponde a uma disciplina ou aula.  
- Os arquivos contêm **resumos, exercícios ou anotações** que fiz durante o curso.
